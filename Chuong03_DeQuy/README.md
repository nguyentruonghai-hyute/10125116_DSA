# Chương 03 – Các bài toán Đệ quy kinh điển

Họ tên: Nguyễn Trường Hải · MSV: 10125116 · Lớp: 10125N.1

## Bài đã làm
- Bài 1: Tính $S(n) = 1 + 2 + \dots + n$
- Bài 2: Tính $S(n) = 1^2 + 2^2 + \dots + n^2$
- Bài 3: Tính $S(n) = 1 + 1/2 + \dots + 1/n$
- Bài 4: Tính lũy thừa $x^n$
- Bài 5: Tìm ước số lẻ lớn nhất của $n$
- Bài 6: Tìm ước chung lớn nhất $\text{UCLN}(a, b)$ bằng giải thuật Euclid
- Bài 7: Đếm số lượng chữ số của $n$
- Bài 8: Tính căn bậc 2 lồng nhau $S(n) = \sqrt{1 + \sqrt{2 + \dots + \sqrt{n}}}$
